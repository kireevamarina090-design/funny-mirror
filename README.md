# 🪞 Кривое Зеркало

Современный сайт-шутка: загружаете фото — и лицо «уродуется» под выбранную тему,
чтобы посмеяться вместе с друзьями. Всё происходит **локально в браузере**:
фото никуда не отправляется.

## Как открыть

Просто двойной клик по `index.html` (работает в Chrome / Edge / Firefox).
Интернет нужен только при первом открытии — с CDN подгружается нейросеть,
которая находит точки лица (MediaPipe Face Landmarks). Нет сети — тоже работает,
эффекты применяются к центру кадра.

## Что умеет

- **14 тем**: Кривое зеркало 🌀, Поросёнок 🐷, Большой мозг 🧠, Клоун 🤡,
  Пришелец 👽, Волшебник 🎅, Зомби 🧟, Пухлые щёчки 😙, Щенок 🐶, Крошечное лицо 🫣,
  Старейшина 🧓, Малыш 👶, Хомяк 🐹, Головастик 🐸.
- Загрузка: кнопкой, **Drag & Drop** и вставкой из буфера (**Ctrl+V**).
- **🎲 Лицо от ИИ** — ИИ сам придумывает новое лицо (свой источник фото не нужен).
- **🔗 По ссылке** — загрузка фото с любого сайта (через weserv-прокси, кроп под лицо).
- **✨ ИИ-генерация** (вкл. по умолчанию): эффект темы рисует нейросеть Pollinations
  `gptimage` (img2img, бесплатно и без ключа): переснимает фото «в тему», сохраняя
  человека; «сила смеха» перекодируется в интенсивность правок; кнопка
  🎲 «Другой вариант ИИ» меняет seed. Свое фото при этом анонимно кладётся на
  tmpfiles.org (~1 час) — без публичного URL img2img не работает. Выключается
  галочкой **«Рисует ИИ»** — кода эффекта тогда отдаёт локальный instant-canvas.
- Ползунок **«Сила смеха»** — интенсивность деформаций и фильтров.
- **🎲 Случайно** — случайная тема со случайной силой.
- Ползунок сравнения **оригинал / результат** прямо на фото.
- **💾 Скачать PNG** результата.
- Деформации: раздувание/сжатие зон лица, растяжение рта, «жидкое» волнение —
  всё на canvas 2D с билинейной выборкой по точкам лица.
- Векторные украшения (очки, уши, антенна, шляпа, борода, румянец…) привязаны
  к точкам лица и остаются на месте при любых пропорциях.
- **🤖 Миничат «Кривуля»**: локальный бот на лёгкие вопросы — время/дата,
  арифметика («сколько будет 7*8»), монетка/кубик, анекдоты, факты и подбор темы
  (сразу применяет её к фото!). По желанию подключается ключ OpenAI-совместимой
  нейросети; ключ живёт только в вашем браузере.
- **🌍 Бесплатный ИИ без ключа**: вшит провайдер Pollinations (модель openai-fast)
  — отвечает на свободные вопросы и решает сложные примеры; вопросы вида
  «кто такой…/что такое…» сами ищутся в Wikipedia (ru → en fallback) и
  подкрепляются ссылкой на источник. Можно отключить в ⚙️ чата.

## Приватность и этика

- **Выключен ИИ** — фото никуда не уходит: вся обработка в вашем браузере.
- **Включён ИИ** — фото на ~1 час кладётся в бесплатный tmpfiles.org и
  передаётся на сервер Pollinations для перерисовки. Оба — публичные сервисы,
  не связывайте секретное с ржачным :).
- Точки лица вычисляет MediaPipe локально (веб-сборка, WASM).
- Пишите только смешные фото людей, которые в курсе шутки.
  Не используйте сайт для травли/дискредитации.
